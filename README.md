# lucky — 个人主页

> **Code with craft. Design with soul.**

边走边画的数字手艺人:一支神笔一路向右画出前路,三只吉祥物(栗子鼠 Chestnut、云朵兔 Cloudy、煤球鸟 Kuro-Kuro)在画好的路上前进。这条路**没有终点**——作品是沿途风景,联系是路边邮筒,结尾是道路消失在纸白远方:未完,还在画。

## 当前状态

- `paper-road/`:M0–M1 手感原型(单文件可玩)。起点村落开场仪式、神笔一笔成景、跳跃/滑行、可插拔作品区、中英双语。
- 设计契约:`个人主页设计与开发方案.md`(v1.3)——先改文档,再写实现。
- 下一阶段:M2–M3 全页滚动与转场,M4 Astro 工程化(`content/works/` 可插拔上线)。

## 本地运行

直接双击打开 `paper-road/index.html`,或起个静态服务:

```bash
cd paper-road
python -m http.server 8931
# 打开 http://127.0.0.1:8931
```

## 操作

| 输入 | 动作 |
|---|---|
| 轻点 / 左键 / Space / ↑ | 跳跃 |
| 右键 / Shift / S / ↓ / 触屏下滑 | 滑行 |
| Esc / ⏸ | 暂停 |
| ↺ 重绘 | 换 seed 重开(`?seed=` 可分享) |

- 任意输入可跳过开场仪式;`prefers-reduced-motion` 时为静态营地 + 「出发」按钮。
- 左键长按**不会**触发滑行;双击永远不绑定滑行;画布上右键无菜单。
- 溪谷、泥洼、石台 → 跳过;低矮通道 → 滑行穿过(整跃可越过拱顶)。
- 笔尖先沿连续墨迹描出主路线与地貌;小队只在已经完成的路线段上前进,笔、地面、角色贴地、倾角、粒子和碰撞共用同一份路线几何。
- 失败只会踉跄 1.5s 然后归队,没有失败结算。

```text
AGENTS.md      仓库协作约定(结构 / 规范 / 校验)
```

## 约定

- 品牌 **lucky**,文案中英双语(zh-CN / en),切换热替换不重载场景。
- **无终点叙事**:页尾是「未完,还在画。 / To be drawn…」,禁止 The End / 终点 / 旅程结束。
- 场景里除天空云朵外的一切都由那支笔画出:主路线与地貌是一笔连续的墨迹,辅助物件随笔尖前沿描出;skip/重绘后由笔快速补画,而非直接出现。
- 营地构图使用单一锚点:篝火 = 小队中心 = 0.22·画布宽,村舍在小队身后,任意窗口宽度下构图一致。
